# Boreas

Notos で書いた小説の表紙や挿絵を作る Tauri デスクトップアプリです。Euros で作ったキャラクターシートを読み込み、3D の下絵をもとに ComfyUI で清書します。

設計は [docs/design.md](docs/design.md) にあります。いまは設計の M4(場所:間取り図・家具と寸法の点検・部屋と家具のデザイン・カメラから見える物)までできています。

## 使い方

1. **設定**:ComfyUI と Ollama の接続を確かめ、Ollama のモデルを選びます。Euros のライブラリの場所も確かめます。
2. **場所**(使うときだけ):「場所」の「新規作成」で部屋を作ります。
   - 間取り:床の形(長方形の組み合わせ)と天井の高さを決め、窓・ドアを壁に置きます(間取り図でドラッグすると壁の上を動きます)。
   - 家具:ベッド・机・椅子・ソファ・テーブル・本棚・タンス・低い棚・テレビ・箱を、実際の寸法(cm)で間取り図にドラッグして置き、回します。3D でも確かめられます。
   - 寸法の点検:部屋に入らない・壁や他の家具にめり込む・ドアや窓をふさぐ・ありえない寸法(高さ3mの椅子など)・天井より高い、を警告します。
   - デザイン:部屋と家具ごとに日本語で説明を書き、「デザインを作る」で ComfyUI に絵を作らせます(英語にしていなければ先に Ollama で英語にします)。直すと、その場所を使うすべての場面に効きます。
3. **場面**の「新規作成」で場面を作り、「人物を足す」で Euros のキャラクターを置きます(人ではない登場人物と合わせて最大4人)。人物ごとに色(赤・青・緑・橙)が付き、下絵ではこの色で描き分けます。素体(女性・男性 × 細身・標準・がっしり)と身長は、キャラクターの説明から決まります(直せます)。
   - 「場所」のタブで場所を選びます(選ばなければ背景は文章だけ)。椅子・ソファ・ベッドに「座らせる」と、座面の高さと向きを合わせます。カメラのタブに、そのカメラから見える家具が出ます。見えない家具はプロンプトに書かず、デザインも渡しません。
4. **人物**:3D の表示で人物をクリックして選び、ドラッグで床の上を動かします。
   - ポーズを一覧から選び、黒い点(手足の先)をドラッグして腕や脚の向きを変えます。
   - 手の形(開く・握る・指差す・ピースなど)、視線(カメラ・ほかの人物・顔の向き)、動作と表情(日本語)を決めます。
5. **人ではない登場人物**:Euros で「人ではない」にしたキャラクターを置きます。形の種類(球・不定形・四足・二足の怪物・物)と大きさ(m)は Euros の `body` から読みます。なければ説明から推定するので、画面か「説明から推定(Ollama)」で直します。
   - 球は浮く高さと傾き、不定形はつぶれ・伸びとへこみ(叩かれた所など)、四足と二足は構え・首・尾・口・腕を決めます。
   - 人物と同じ色の並びで色が付き、Picture 2 以降に人物のシートの次に渡します。
6. **小物**:バット・剣・棒・円柱・球・箱を、実際の寸法(cm)で置きます。Euros の装備品も選べます(寸法とデザインの画像は Euros の値)。長い物は人物の手に持たせ、持つ位置と向きを決めます。
7. **大きさの誇張**:小物と人ではない登場人物は、場面だけ大きさを変えられます(全体・長さ・太さの倍率)。下絵もその大きさで描き、プロンプトで「わざと大きく描いている」と伝えます。Euros の寸法は変えません。
8. **触れる**:「鈴のバットの先 → スライムの上」「Aの右手 → Bの肩」のように、触れる点を決めます。手や小物の先がそこに寄り(へこみがあれば、へこみの底)、プロンプトで清書に伝えます。印は編集の画面にだけ出ます。
9. **カメラ**:表紙・挿絵(縦・横)の枠を選び、「全身・膝上・胸上」かドラッグでカメラを決めます。
10. **清書**:背景を日本語で書き、「英語にする」でプロンプトの英語を作ります。「清書する」で、3D の下絵と登場人物のシート・装備品のデザイン・部屋と見える家具のデザインを ComfyUI(MiniMax-H3-Image)に渡して候補を作ります(1枚に6分ほど。部屋と家具のデザインは、下絵を含めて画像が6枚になるまでで、多いときは見えている割合の大きい家具から)。
11. 候補から1枚を「採用」し、「書き出す」で PNG に保存します。

## 必要なもの

- [ComfyUI](https://github.com/comfyanonymous/ComfyUI)(`http://127.0.0.1:8188` で起動)と、MiniMax-H3-Image のモデル
- [Ollama](https://ollama.com/)(`http://127.0.0.1:11434` で起動)と、日本語を扱えるモデル
- [Euros](https://github.com/kurone-hinamori/Euros) で作ったキャラクター

## 開発

```
npm install
npm run tauri dev
```

開発サーバーは、Euros・Notos(1420)と同時に動かせるよう 1430 番を使います。

確かめるとき:

```
npm run build
cargo test --manifest-path src-tauri/Cargo.toml --lib
```

## 素体

人物の素体は MakeHuman(CC0)で作った `public/figures/*.glb` です。作り直すときは、Blender 5.2 と MPFB2 の拡張機能を入れて次を実行します。

```
blender -b --python tools/make_figure.py -- --all public/figures
```

ポーズは `src/lib/poses.ts` にあります。開発サーバー(`npm run dev`)で `http://localhost:1430/dev/poses.html` を開くと、すべてのポーズを並べて確かめられます。

人ではない登場人物の形は `src/lib/creatures.ts` で、型と大きさから three.js で作ります(素体のファイルはありません)。`http://localhost:1430/dev/creatures.html` で形の種類と、鈴がバットをスライムに振り下ろす場面の下絵を確かめられます。

場所の部屋と家具は `src/lib/place.ts` で、間取り(cm)から three.js で作ります。`http://localhost:1430/dev/places.html` で、確かめる部屋(鈴の部屋)の寸法の点検と、同じ部屋の2つの場面(机・ベッド)の下絵・見える家具・プロンプトを確かめられます。`dev/verify/capture.mjs`(headless Chrome でこのページの出力を保存)と `dev/verify/refine.mjs`(デザインと清書を ComfyUI で作る)で、清書まで確かめられます(使い方は各ファイルの先頭)。

## 保存先

- Boreas が書く場所:既定は `%APPDATA%\Boreas\library\`。設定で変えられます。
  - `scenes\<id>\scene.json`(場面)、`sketches\<id>.png`(下絵)、`results\<id>.png`(清書の候補)
  - `places\<id>\place.json`(場所:間取り・窓とドア・家具の型と寸法と位置・説明)、`designs\<id>.png`(部屋・家具のデザイン。作り直しても前の画像は消しません)
  - 消した場面と場所は `.trash\` に移します。
- 読むだけの場所:Euros のライブラリ(既定は `%APPDATA%\Euros\library\`。キャラクターは `characters\<id>\character.json`、装備品は `equipment\<id>\equipment.json`)と Notos のデータ(既定は `%APPDATA%\io.github.kurone-hinamori.notos\`)。Boreas はこれらを書き換えません。

## リリース

- GitHub の Actions で **Bump version** を実行すると、バージョンを上げてタグを付け、インストーラーと自動アップデート用の `latest.json` を Releases に公開します。
- `v*` のタグを手で push しても同じようにリリースされます。
- 更新の署名鍵は `~/.tauri/boreas.key`(パスワードは `~/.tauri/boreas.key.password`)にあります。公開鍵は `src-tauri/tauri.conf.json` の `plugins.updater.pubkey` に入っています。
  - 秘密鍵とパスワードは、リポジトリの Secrets の `TAURI_SIGNING_PRIVATE_KEY` と `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` に登録します。
  - 鍵をなくすと、インストール済みのアプリに更新を届けられなくなります。バックアップしてください。
